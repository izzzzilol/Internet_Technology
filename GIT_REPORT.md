
# Отчёт по практической работе Git и Git Flow

## 1. Цель работы

Изучить основы системы контроля версий Git, научиться работать с удалённым репозиторием GitHub, создавать ветки, выполнять слияния, разрешать конфликты и применять Git Flow.

## 2. Информация о проекте

- GitHub: izzzzilol
- Репозиторий: Internet_Technology
- Операционная система: Windows 11
- Среда разработки: PyCharm
- Основная ветка: main
- Ветка разработки: develop

## 3. Основные команды Git

| Команда | Назначение |
|---|---|
| git init | Создание локального репозитория |
| git clone | Клонирование удалённого репозитория |
| git status | Проверка состояния файлов |
| git add | Добавление изменений в индекс |
| git commit | Создание коммита |
| git push | Отправка изменений на GitHub |
| git pull | Получение изменений из удалённого репозитория |
| git switch | Переключение между ветками |
| git branch | Просмотр и создание веток |
| git merge | Слияние веток |
| git diff | Просмотр различий между версиями |

## 4. Использование Git Flow

В работе использовались следующие типы веток:

| Ветка | Создаётся от | Сливается в | Назначение |
|---|---|---|---|
| main | — | — | Стабильная версия проекта |
| develop | main | — | Интеграция новых изменений |
| feature/* | develop | develop | Разработка новых функций |
| release/* | develop | main и develop | Подготовка релиза |
| hotfix/* | main | main и develop | Исправление срочных ошибок |

## 6. Разрешение конфликта

Во время слияния веток возник конфликт в файле sandbox/hello.txt.

Причиной стало изменение одного и того же файла в двух ветках.

Конфликт был разрешён вручную: выбрано итоговое содержимое файла, удалены служебные маркеры конфликта, после чего изменения были добавлены и сохранены отдельным коммитом.

## 7. Выполнение Hotfix

Была создана ветка hotfix/izzzzil-typo от main.

В файле sandbox/hello.txt была исправлена опечатка в слове sample. Затем исправление было объединено с ветками main и develop.
